7년차 Android 개발자

뷰티샵의 예약·고객·매출을 관리하는 B2B SaaS 앱을 중심으로 교육, 헬스케어, 암호화폐 거래소 앱을 만들었습니다.

레거시 앱에 Kotlin·Compose·MVI를 단계적으로 적용했고, AI로 테스트와 반복 개발 작업을 자동화했습니다. 앱의 문제를 직접 찾아 고치고, 스터디를 열어 팀원들과 새 기술을 함께 적용했습니다.

스타트업에서 Android를 혼자 또는 소수로 맡는 경우가 많아, 구조 설계부터 배포와 운영까지 챙겼습니다. 개발 전에는 기획·디자인·백엔드·QA와 정책과 예외 상황을 먼저 맞추고, 합의한 내용은 컨벤션과 가이드 문서로 남겼습니다. 최근에는 Android·iOS·QA 팀의 리더를 맡아 회고와 1on1으로 구성원의 업무와 성장을 챙겼습니다. 컨퍼런스와 IT 동아리 활동으로 꾸준히 배우고 있습니다.

    테스트 자동화 · 2026.02 ~ 03 · 기여도 100%

    자주 수정되는 매출 ViewModel은 회귀 버그가 잦았지만 직접 만들어 쓰던 테스트 코드 작성 스킬로는 커버리지 20.6%에서 더 오르지 않았습니다. 필요한 테스트 코드가 AI가 한 번에 다룰 수 있는 컨텍스트 양을 넘었고 생성된 테스트가 실패하면 사람이 다시 요청해 같은 작업을 반복해야 했습니다. 기존 스킬을 바탕으로 테스트를 기능 단위로 나눠 실행하고 실패한 테스트는 Ralph Loop로 통과할 때까지 스스로 진단해 고치는 단계를 더한 파이프라인을 Claude Code로 설계했습니다.
